# Documentation

- `README.md`: Human entry point (mission, usage, release validation).
- `AGENTS.md`: Machine instructions.
- `ARCHITECTURE.md`: Technical flow and execution architecture.
- Keep tests and docs synchronized. If a limitation is found, update `README.md` and `docs/public-api-boundary.md`.
